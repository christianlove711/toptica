# TOOPTICA 实验室控制软件

这是一个最小可运行的 PySide6 桌面应用骨架，用于连接和控制 TOOPTICA 激光器。
底层通信使用官方 `Python LaserSDK`，上层界面和逻辑则按实验室自己的需求来组织。

## 功能

- PySide6 图形界面壳子
- `TOOPTICAController` 通信封装
- 支持真实设备网络连接或串口连接
- 支持 `Demo mode`，没有设备时也能先调界面
- 基础状态读取与周期刷新
- 参数浏览器页面
- 自定义参数探针，可手动读取任意参数
- 参数收藏 / 参数白名单页面
- 本地保存实验室自己的参数说明书草稿

## 快速开始

1. 创建并激活虚拟环境或 conda 环境。
2. 安装依赖：

```bash
pip install -r requirements.txt
```

3. 启动程序：

```bash
python3 app.py
```

如果你使用 conda 环境，也可以这样运行：

```bash
conda run -n toptica-lab python app.py
```

## 使用说明

- 如果没有真实设备，可以输入 `demo`，或者直接勾选 `Demo mode`。
- 网络设备可填写 IP、DNS 名称、设备序列号或系统标签。
- 串口设备请选择 `Serial`，并填写串口名，例如 macOS 下的 `/dev/tty.usbserial`，或 Windows 下的 `COM3`。
- `Parameter Browser` 页面内置了一批推荐参数，覆盖设备标识、电流、温度、扫描、锁定、记录器和系统诊断等常见方向。
- 当前程序默认读取一组较安全的基础参数：
  `system-type`、`serial-number`、`system-label`、`ul`、`uptime-txt`、`laser1:dl:cc:current-act`。
- 当前项目优先使用 LaserSDK 的低层 API，这样对具体 DLC 固件版本的耦合更低，也更适合实验室后续自己扩展。

## 页面说明

### 1. Overview

- 用于连接设备并显示基础状态。
- 连接成功后会显示设备类型、序列号、系统标签、用户级别、运行时间和当前二极管电流。
- 程序默认每 2 秒刷新一次基础状态。

### 2. Parameter Browser

- 这是参数探索页面。
- 上方表格内置了一批推荐参数，适合先用来确认设备支持哪些功能。
- 可以在过滤框中搜索 `current`、`temp`、`lock`、`scan`、`recorder` 等关键词。
- 点击 `Refresh listed values` 可以批量读取当前表格中的参数值。
- 下方 `Parameter Probe` 可以手动输入任意参数名并立即读取。

#### 推荐使用方式

1. 先连上设备。
2. 在 `Parameter Browser` 中刷新推荐参数。
3. 找到读得通、值正常的参数。
4. 再用 `Parameter Probe` 试更多参数路径。

### 3. Favorites

- 这是参数收藏 / 参数白名单页面。
- 你可以把已经验证过的参数保存下来，逐渐形成实验室自己的参数手册。
- 每个收藏参数都可以记录这些信息：分组、参数名、读写属性、描述、备注。
- 收藏页支持刷新当前值，也支持删除不需要的参数。

## 如何建立实验室自己的参数说明书

建议按下面的方法逐步整理：

1. 先连接真实设备。
2. 在 `Parameter Browser` 里读取推荐参数。
3. 把确认存在且有意义的参数加入 `Favorites`。
4. 在保存时补充中文说明，例如这个参数表示什么、单位是什么、是否允许学生修改、修改风险高不高。
5. 继续用探针尝试更多参数，并把验证成功的继续加入收藏。

这样你最后就会得到一份实验室自己的参数白名单，而不是依赖零散记忆。

## 收藏参数如何保存

- 收藏参数会保存到项目目录下的：

```text
data/parameter_favorites.json
```

- 这个文件建议纳入你们项目管理，后面可以持续补充。
- 它本质上就是你们实验室版的参数说明书草稿。

## 目前更适合做的事

当前这版程序更适合：

- 连接设备
- 识别基础信息
- 探索和验证参数
- 建立参数白名单

还不建议直接开放高风险控制动作，比如：

- 激光出光开关
- 电流设定值写入
- 温控设定值写入
- 扫描参数写入
- 锁定参数写入

这些功能建议等你们把参数白名单和安全策略整理好以后再逐步加入。
